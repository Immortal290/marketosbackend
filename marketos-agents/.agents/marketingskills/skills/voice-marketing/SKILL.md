# Voice Marketing

## What voice marketing actually means

Voice marketing covers: podcast ads, audio ad spots, IVR scripts, voice assistant skills, and spoken content designed for audio-first consumption. The medium completely changes the copy rules — there is no scan, no re-read, no visual hierarchy. The listener gets one pass.

## Core rules for audio copy

- **Front-load the hook.** The first 5 seconds of audio are the skip decision point. Lead with the most interesting, counterintuitive, or emotionally resonant element. Product names and brand identifiers go last, not first.
- **Write for the mouth, not the eye.** Read every script aloud before finalizing. If any sentence requires a breath mid-clause, break it into two sentences. Contractions are mandatory — nobody speaks in formal constructions.
- **Avoid parenthetical structure.** Visual asides (like this) are invisible in audio. Any clarification must be woven into the sentence flow.
- **The ear holds fewer items than the eye.** Maximum 3 items in any list. Zero acronyms unless previously spelled out. No URLs unless they are simple, memorable, and repeated.

## Podcast ad script structure (30-second spot)

```
[0–5s]   HOOK: Situation the listener recognizes from their own life
[5–15s]  PROBLEM: Sharpened version of the pain. One specific detail.
[15–22s] SOLUTION: What the product does, stated as transformation not feature.
[22–28s] SOCIAL PROOF: One number or one named result.
[28–30s] CTA: Single action, memorable URL or phrase. Repeated twice if time allows.
```

## Podcast ad script structure (60-second spot)

```
[0–8s]   HOOK: Counterintuitive statement or story opening
[8–20s]  PROBLEM: Deeper paint of the pain, listener's internal monologue
[20–35s] SOLUTION: How the product works, concrete and specific
[35–50s] PROOF: Named customer or verified number + the specific result
[50–58s] OFFER: Time-bound or exclusive deal for podcast listeners
[58–60s] CTA: URL + repeat the URL
```

## Memorable URL rules for audio

- Maximum 3 syllables if possible. "go.marketOS.io/pod" is fine. "marketosdashboard.com/podcast-listeners-special-offer" is dead on arrival.
- If the URL is complex, use a redirect and give the show a dedicated vanity URL.
- Repeat the CTA URL twice in the final 5 seconds. Listeners often can't write while driving.

## Tone calibration by format

- **Podcast mid-roll:** Conversational, host-read tone preferred (even when scripted). First person from host perspective sounds more trusted than announcer voice.
- **Radio/streaming audio ad:** Higher energy, shorter sentences, more compression.
- **Voice assistant skill:** Confirm the user's intent before doing anything. Never surprise. Every response must include the next available action.
- **IVR scripts:** Clarity over everything. 8-word max per instruction. Read back decisions before confirming. Assume the caller is in a stressful situation.

## Anti-patterns for voice copy

- Opening with the brand name. "Hi, I'm [Brand]!" — the skip rate on this is extremely high.
- Reading a web page script verbatim. Web copy and audio copy are entirely different registers.
- Technical jargon or acronyms that require visual context.
- Asking the listener to "visit our website to learn more" without giving the actual URL.
